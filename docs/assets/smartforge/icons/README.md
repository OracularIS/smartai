# SmartForge Icons (Extracted)

These SVGs were extracted from `smartforge_light.svg` and normalized for reuse in documentation.

- `*-120.svg`: Large boxed icon (120x120)
- `*-72.svg`: Splash icon (72x72)
- `*-28.svg`: Nav icon (28x28)
- `*-naked.svg`: Transparent icon (no background box); best for dark backgrounds and inline headings

Files:
- `smartforge-parent-*`: SmartForge (parent platform mark)
- `smartforge-studio-*`: SmartForge Studio
- `smartforge-nexes-*`: SmartForge Nexes
- `smartforge-cortex-*`: SmartForge Cortex
